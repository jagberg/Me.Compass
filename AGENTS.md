# Me.Compass — Personal Action Manager

Decisions: `docs/adr/` and `CHANGELOG.md` — read before proposing architecture changes.

A local, single-user tool that aggregates actions owed to the user from
Gmail, Google Drive/Gemini meeting notes, and Google Chat, flags overdue
items, and uses the local Codex CLI to infer missing due dates/priority
and suggest next steps.
